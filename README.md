## What I've Built

### ShopNest: MERN E-Commerce
[Live](https://shop-nest-e-commerce-website.vercel.app/) · [Code](https://github.com/Siva-242006/ShopNest-E-Commerce-Website)

- **Problem:** duplicate orders, overselling and admin-route access in a multi-user store
- **What I did:** added a 30-second duplicate-order guard (HTTP 409), atomic guarded stock updates in MongoDB, and JWT/RBAC so customers get a 403 on admin routes
- **Optimization:** route-level code splitting cut initial JS by **37%** (122.5 → 77.6 kB gzip), and replacing framer-motion with CSS cut the Orders route by **95%** (39.3 → 1.9 kB)
- **Proof:** **72 tests** (83% line coverage), 3 Playwright E2E suites and New Relic APM monitoring

### Persona Support Agent: RAG Customer Support
[Live](https://persona-support-agent-oxxj.onrender.com) · [Code](https://github.com/Siva-242006/persona-support-agent)

- **Problem:** support bots give unsupported answers, hit API rate limits, and can't tell when a human should take over
- **What I did:** built a RAG pipeline over 10 documents that answers only from retrieved context above a **0.45 similarity threshold**, with query-term verification
- **Optimization:** exponential backoff, jitter and automatic failover across **7 Gemini model variants** to survive rate limits
- **Impact:** **6 escalation triggers** (billing, refund, legal and more) generate structured JSON handoff tickets, and a persona classifier adapts to technical, frustrated or business users
